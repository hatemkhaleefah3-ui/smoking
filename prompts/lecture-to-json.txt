14. Use callout blocks sparingly for definitions, important points, notes, or warnings clearly supported by the source.
15. Use table blocks only when the information is genuinely tabular. Every row should have the same number of cells as the headers.
16. Use code blocks only for code or commands present in the source.
17. All values must be plain JSON strings. Do not put HTML or Markdown inside strings.
