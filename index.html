Image-aware workflow

Import, add images, publish

  1. Import the lecture JSON file.
  2. Select Build to validate it and reveal every image label.
  3. Choose one local image for each required label.
  4. Select Continue to upload the images and create the permanent link.
  5. Select Preview to open the finished website with its images.
