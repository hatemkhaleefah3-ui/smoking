Workflow

From lecture text to HTML

  1. Attach a plain-text lecture file to ChatGPT.
  2. Use the prompt in prompts/lecture-to-json.txt.
  3. Save ChatGPT’s JSON-only response as a .json file.
  4. Import it here, verify the preview, and download the HTML file.
Everything runs locally in your browser. Imported files are not uploaded by this page.
