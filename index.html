Shareable workflow

Build, publish and share

  1. Choose the JSON file and select Build.
  2. Select a design and choose Preview & publish.
  3. Copy the permanent URL from the new page or the Copy link button.
  4. Send it to anyone. The same link loads the saved lecture whenever it is opened.
