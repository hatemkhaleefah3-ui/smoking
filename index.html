How it works

Build and preview

  1. Select a lecture design.
  2. Choose the JSON file created from your lecture.
  3. Select Build to validate and prepare the lecture.
  4. Select Preview to open only the finished lecture in a new page.
No file yet? Preview uses the included example lecture until you build your own JSON file.
Everything runs locally in your browser. Imported files are not uploaded by this page.
